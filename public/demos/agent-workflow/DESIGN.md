# Agent 1.2 · 谁在决定下一步

## Style Prompt
沿用学习网站的浅色教学界面与蓝色强调色。演示像一张可以逐步展开的实验记录：三列使用相同尺度与同一任务，差异落在决策归属和观察反馈。内容优先，动画只引导阅读，不表现真实模型推理。

## Colors
- Canvas: #f8faff
- Ink: #243d59
- Secondary ink: #52677e
- Accent: #254c82
- Evidence background: #e4edf8

## Typography
中文使用 Microsoft YaHei / PingFang SC，步骤编号使用 Consolas。标题重量 900，正文 400；渲染宽度 1440 × 1440 时标题 60px、正文 24px。嵌入课程时按断点调整字号并在窄屏纵向排列。

## Motion
单场景、20 秒、可暂停和定位。先呈现任务，再沿三个泳道显示观察和行动。使用 power3.out、sine.out、expo.out 区分标题、信息和动作入场。尊重减少动态效果偏好，默认不自动播放。

## What NOT to Do
- 不把固定条件分支描述成没有判断能力。
- 不把未接工具的聊天例子推广成所有聊天产品。
- 不把预设动画说成实时模型执行。
- 不用装饰动画抢占阅读时间，不自动循环。
- 不用颜色独自表达状态，不裁切中文，不让动画替代完整文字。

## Review notes
此交付为课程内可操作演示，刻意不加入音频，使用 20px 以上说明文字而非社交视频的 37px 字号门槛。播放器初始定位在 0.95s，使任务与输入可见；导出电影时 0s 的入场帧并非课程初始画面。
