认识 Agent · 1.1

AI 会回答，为什么还需要 Agent？

AI 可以告诉你代码该怎么改。把任务做完，还需要查看项目、修改文件、执行测试，并根据结果继续调整。

先理解架构

Agent 怎样把任务做完？

模型 + 工具 + 反馈循环

模型负责选择行动，工具把行动落到程序中，执行结果再回到模型。

▤

为模型提供依据
✦
模型结合目标，选择下一步

⌘

→
↳
执行结果返回文件、报错或测试回执
↶观察与反思结果回到模型，调整行动，直到完成。

本例用到计划、工具、项目记忆和反思，具体机制按任务选择。演示推进时，对应环节会高亮。
