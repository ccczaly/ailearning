Takeaway 复杂任务不靠一个 Agent 硬撑，而是拆成多个专职子 Agent：调研员负责读代码、开发者负责改代码、测试员负责验证。独立任务可并行，有依赖或共享写入的任务需要协调。这就是 Agent 世界的团队协作。
