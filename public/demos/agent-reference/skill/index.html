准备开始
没有 Skill 的 ReAct
本质：Skill 就是把经验写成文档，算不上新技术。用自然语言告诉 AI：遇到这类任务，先做什么、再做什么、调哪个工具。AI 出门之前就想清楚，一趟全搞完。
对应的 SKILL.md 文件 ↓（好循环的秘密）
📄 SKILL.md
支持技能文件的运行环境 可读取技能入口与配套资源。本例使用一个 SKILL.md 文件，具体发现、加载和权限方式由运行环境决定。写好 Skill = 把你的经验变成 AI 的能力。

教学预设：所有对话、动作、执行结果、次数、Token、时间和费用均为示例数据，不会调用真实模型、执行命令或产生预订/发布。技能说明与风险分类不能替代程序权限检查。
